# Personal Portfolio Website

My personal portfolio website built to present information about me and provide links to selected projects.  
The website focuses on **clean semantic HTML, optimized CSS, and performance**, without using heavy frontend frameworks.

This project demonstrates a **classic frontend workflow** using modern build tools and animations.

---

## 🌐 Overview

The portfolio website includes:

- Personal introduction and background
- Links to portfolio projects
- Clean, minimal UI
- Smooth scroll animations
- Optimized and production-ready assets

It serves as a central hub for showcasing my work and experience.

---

## 🛠 Tech Stack

### Core

- HTML5 (semantic markup)
- CSS3 / SCSS
- JavaScript (ES6+)

### Build & Tooling

- Gulp
- Webpack
- Babel
- BrowserSync

### Optimization

- CSS minification
- HTML minification
- Image optimization
- Autoprefixing

### Animations

- AOS (Animate On Scroll)

---

## ✨ Features

- 📄 Semantic and accessible HTML structure
- 🎨 SCSS with modular styling
- 🚀 Optimized build for production
- 🔄 Live reload during development
- 🖼 Image optimization pipeline
- ✨ Scroll-based animations
- 💻 Cross-browser compatibility

---

## 🎯 Project Goal

This project was created to:

- Build a **lightweight, fast portfolio website**
- Demonstrate strong fundamentals in **HTML, CSS, and JavaScript**
- Work with modern **build tools and asset pipelines**
- Avoid unnecessary frameworks for a content-focused site
